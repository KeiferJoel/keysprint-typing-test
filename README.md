# ⌨️ KeySprint

> Improve your typing speed and accuracy with a clean and modern typing test built using **HTML, CSS, and Vanilla JavaScript**.

---

## ✨ Features

* ⌨️ Real-time typing test
* 🟢 Correct and 🔴 incorrect character highlighting
* ⏱️ 30-second countdown timer
* 📊 Live statistics

  * Words Per Minute (WPM)
  * Accuracy
  * Errors
* 📈 Animated progress bar
* 🔄 Restart the test with a new random text
* 📱 Responsive design for desktop, tablet, and mobile

---

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (Vanilla)

No frameworks or external libraries were used.

## 🚀 Getting Started

1. Clone this repository.

```bash
git clone https://github.com/KeiferJoel/keysprint.git
```

2. Open the project folder.

3. Run `index.html` in your favorite web browser.

No installation or dependencies are required.
